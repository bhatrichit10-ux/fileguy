# fileguy
my own file manager!
# Features
- Fully CLI
- CLI syntax highlighting
- View Files 
- See current working directory
- Select and navigate seamlessly using WASD or Arrow keys
- Enter to select
# Install
```
# install
$ npm i -g fileguy

# usage
$ fileguy
```
